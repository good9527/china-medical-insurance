## 一、审计背景与目标

为彻底贯彻落实“每一项数据必须有据可查，严禁任何主观臆造或幻觉，以当地政府办公厅、医保局等官方公开发布的正式红头文件为法定溯源依据”的核心原则，本项目开展了针对全国 348 个医保统筹区的全量、穿透式深度核验工程。

### 核心审计目标：
1. **公文法定溯源核验**：核实每个统筹区是否具备 2 篇以上现行有效、带正式文号与公开可访问 URL 的规范性公文，杜绝废止或失效规章。
2. **法定报销比例与起付线穿透**：
   - 职工与居民普通门诊统筹起付线、封顶线、基层/二级/三级医疗机构差异化比例、退休人员倾斜待遇；
   - 职工与居民住院各级医疗机构（基层/一级/二级/三级/重点三甲）起付标准与分段报销比例；
   - 城乡居民大病保险与职工大额医疗互助的起付标准、分段梯次报销比例及封顶规则；
   - 异地就医直接结算报销比例折算系数（长期异地、规范转诊、急诊抢救、未备案临时就医）。
3. **消除历史模板覆盖残留与层级倒挂**：
   - 清理前期模板脚本批量写入导致的统筹区同质化偏差；
   - 修复高等级医院报销比例反向高于低等级医院的倒挂现象（如部分三甲医院报销比高于社区）；
   - 清除居民门诊统筹误填住院各级起付线的复制残留。

## 二、审计工具链与核验方法

我们构建了多层级自动化巡检与深度核验工具链：

1. **规范性与完整性核查引擎 (`npm run audit:data`)**：
   - 验证所有 348 个统筹区文件 TypeScript 静态类型完整性；
   - 校验文号格式（包含年份括号与号字）、官方发布机构、URL 协议及各保障层级字段齐全性。
2. **多维规则与非标比例智能巡检引擎 (`npm run audit:smart`)**：
   - 巡检各层级起付线单调递增律（社区 <= 一级 <= 二级 <= 三级）；
   - 巡检报销比例单调递减律（社区 >= 一级 >= 二级 >= 三级）；
   - 跨省异地就医备案折算系数校验；
   - 敏感非标过渡比例排查（`ODD_TRANSITION_RATIO`）与法定特例白名单联动。
3. **全域公文条款摘录深度对齐引擎 (`src/scripts/deep-nationwide-audit.ts`)**：
   - 提取各统筹区 `sourceDocs[].summaryQuote` 中由当地政府、医保局正式红头文件明确记载的各项参数；
   - 与代码数据结构中的起付线、比例进行严格交叉比对；
   - 检出参数与公文摘录不一致的统筹区并生成修复清单。
4. **待遇计算全量自动化断言套件 (`npm run test:calc`)**：
   - 覆盖全国 348 统筹区的基础算例、门诊梯度、住院待遇、大病保险二次报销、CMI-Index 2.0 评测雷达断言。
